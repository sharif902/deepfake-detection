## Results and Output Storage

The project uses a dedicated `results` directory to organize outputs generated during program execution. Each processing module stores its generated outputs in its corresponding results directory.

```text
results/
├── evaluate_unseen_results/
└── plot_metrics_result/
```

### Evaluation Results

When `evaluate_unseen.py` is executed, the evaluation results generated by the program are stored in:

```text
results/evaluate_unseen_results/
```

This directory contains the outputs produced during evaluation on unseen data.

### Metric Visualization Results

When `plot_metrics.py` is executed, the generated performance plots and metric visualizations are stored in:

```text
results/plot_metrics_result/
```

The directory contains the visualization outputs generated from the evaluation metrics.

### Detection and Grad-CAM Outputs

During image or video analysis, generated prediction outputs and Grad-CAM visualizations are saved to the configured results location on the local device. Grad-CAM visualizations are generated for the applicable fake-image predictions to provide visual interpretation of the model's decision.

All generated output files are stored separately from the source code and input data, keeping the project structure organized and making the generated results easy to locate and review.

The `results` directory is therefore intended for **runtime-generated outputs**, and its contents are produced by executing the corresponding project programs on the user's local device.
